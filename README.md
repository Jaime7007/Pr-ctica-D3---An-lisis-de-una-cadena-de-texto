Práctica D3 — Análisis de una Cadena de Texto

Programa desarrollado en Python (1° DAW - Programación) que solicita una frase al usuario y genera un informe detallado con múltiples métricas y transformaciones de texto.

Características del Programa

El script está estrictamente modularizado en funciones independientes, calculando cada dato de forma específica:

Número de caracteres: Longitud total de la cadena introducida.

Número de vocales: Conteo de vocales (incluyendo acentos y mayúsculas/minúsculas).

Número de consonantes: Conteo de consonantes alfabéticas.

Número de dígitos: Detección de caracteres numéricos mediante el método isdigit().

Número de espacios: Conteo de espacios en blanco.

Letra más repetida: Determina el carácter alfabético más frecuente (ignorando espacios, símbolos y dígitos).

Comprobación de palíndromo: Valida si la frase se lee igual al derecho y al revés, ignorando espacios y signos de puntuación.

Inversión de frase: Recorre la cadena mediante un bucle acumulador para mostrarla invertida.
